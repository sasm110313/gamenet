راهنمای اتصال
  1. فایل .rdp را دانلود کنید و روی کامپیوتر ویندوزی خود باز کنید.
  2. نام کاربری و رمز یک حساب ویندوزی همین سرور را وارد کنید.
  3. این حساب باید عضو گروه Remote Desktop Users باشد (حساب Administrator به‌صورت پیش‌فرض مجاز است).
  4. اتصال از داخل سالن/LAN با آدرس بالا انجام می‌شود؛ برای دسترسی از خارج سالن از VPN/Tailscale استفاده کنید و پورت 3389 را روی اینترنت باز نکنید.
اگر سیستم سرور بدون رمز عبور باشد، ویندوز اجازه اتصال RDP نمی‌دهد. ابتدا یک رمز برای حساب ویندوز تنظیم کنید.
