================================================================
 GameNet 0.2.4 — بسته نصب و به‌روزرسانی (کلاینت + سرور سالن + ابر)
================================================================

تغییرات مهم این نسخه
---------------------
• نمای جدولی کامل ایستگاه‌ها در کنار نمای کارتی (هاب و ابر).
• ریسپانسیو کامل برای مدیریت با موبایل.
• رفع کندی صفحه جزئیات/شارژ مشتری (رهرو غیرمسدودکننده).
• رفع خطای «database is locked» هنگام تغییر رمز مشتری/ادمین در هاب
  (WAL + تراکنش IMMEDIATE + ذخیره اتمیک).
• فرمان آپدیت سرور برای هاب آفلاین تا ۷ روز نگه داشته و در اولین
  اتصال به ابر تحویل داده می‌شود.
• رفع ۳۲ باگ مالی/اداری پنل ادمین.

ساختار
------
client/       نصب‌کننده و آپدیتر کلاینت + app.asar + latest.json
server-hub/   نصب‌کننده و آپدیتر سرور هاب + zip آپدیت + latest.json
cloud/        بسته کد ابر + اسکریپت آپدیت امن

نصب/آپدیت کلاینت
-----------------
نصب تازه: GameNet-0.2.4-win7-ia32.exe (Run as administrator)
آپدیت:    GameNet-Client-Update-0.2.4.exe  یا خودکار از هاب

نصب/آپدیت سرور هاب
-------------------
نصب تازه: GameNet-Server-0.2.4-Setup.exe (Run as administrator)
آپدیت:    GameNet-Server-Update-0.2.4.exe  (پوشه backend\data حفظ می‌شود)
از راه دور: GameNet-Server-Update-0.2.4.zip

آپدیت ابر
----------
bash deploy_cloud_update.sh gamenet-cloud-0.2.4.tar.gz

بررسی فایل‌ها: sha256sum -c SHA256SUMS.txt
