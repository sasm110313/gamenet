GameNet 0.2.10 — بسته نصب و آپدیت

نصب جدید:
- هاب Windows 10/11 x64: server-hub/GameNet-Server-0.2.10-Setup.exe
- کلاینت Windows 7 SP1 / ۳۲ بیتی: client/GameNet-0.2.10-win7-ia32.exe
- کلاینت Windows 10/11 x64: client/GameNet-0.2.10-win10-x64.exe

آپدیت نصب موجود:
1. ابتدا از دیتابیس و تنظیمات پشتیبان بگیرید.
2. ابر: با root اجرا کنید: bash cloud/deploy_cloud_update.sh cloud/gamenet-cloud-0.2.10.tar.gz
3. هاب: server-hub/GameNet-Server-Update-0.2.10.exe را با Administrator اجرا کنید.
4. کلاینت: client/GameNet-Client-Update-0.2.10.exe یا آپدیت خودکار هاب.
ابر و هاب باید هر دو به نسخه جدید برسند.

اصلاحات این دور:
- وابستگی و قطع/اتصال مجدد WebSocket، تغییر مقصد ابر، خطای ارسال و اجرای ORM در async.
- پاسخ JSON نامعتبر ابر، صف ACK ناقص، بازیابی watermark و retry واقعی رویداد ردشده.
- صف پایدار ارسال نشست به رهرو در همان تراکنش مالی؛ ارسال مجدد پس از قطعی.
- یک مالک ارسال برای نشست‌های جدید؛ اطلاعات مصرف کوپن و تغییر موجودی کوپن در سینک.
- رفع خطاهای مخفی webhook رهرو، انتقال هش رمز به هاب و حفظ کوپن وقتی فیلد در پیام نیست.
- حذف retry خودکار مصرف کوپن روی مقصد دوم پس از timeout.
- آپدیتر سرور شامل وابستگی WebSocket برای نصب‌های قبلی است.

راستی‌آزمایی:
113 تست منتخب بک‌اند + 17 تست Electron موفق؛ TypeScript و بررسی migration موفق.
یک تست قدیمی پیش‌فرض‌های کسب‌وکار از مجموعه منتخب کنار گذاشته شد؛ مجموعه قدیمی کامل سبز نیست.
تست شبکه روی WebSocket محلی و پاسخ‌های شبیه‌سازی‌شده انجام شد.
هیچ تراکنش واقعی روی رهرو یا استقرار روی ابر زنده انجام نشد.
نصب واقعی روی ویندوز در این محیط انجام نشده است.
retry رهرو از session_id و کلید idempotency ثابت استفاده می‌کند؛ تضمین دقیقِ یک‌بارمصرف بودن نیازمند پشتیبانی API رهرو است.
