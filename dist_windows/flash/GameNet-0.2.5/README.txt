================================================================
 GameNet 0.2.5 — بسته نصب و به‌روزرسانی (کلاینت + سرور سالن + ابر)
================================================================

تغییرات مهم این نسخه
---------------------
• رفع خطای به‌روزرسانی کلاینت (کپی app.asar با دسترسی ادمین، تشخیص خطای
  واقعی کپی و تلاش مجدد، مسیر امن برای UAC).
• رفع «database is locked» هنگام تغییر رمز مشتری/ادمین در هاب
  (WAL + تراکنش IMMEDIATE + ذخیره اتمیک + ARP خارج از تراکنش).
• رفع NameErrorهای پنل ابر (تنظیمات/مشتری) که دکمه‌های به‌روزرسانی را
  از کار انداخته بود.
• تحویل فرمان‌های آپدیت به هاب آفلاین هنگام اتصال مجدد (تا ۷ روز).
• نمای جدولی ایستگاه‌ها در کنار نمای کارتی + ریسپانسیو موبایل.
• قابلیت جدید: «دسکتاپ سرور (RDP)» در پنل هاب — نمایش آدرس، دانلود فایل .rdp
  و فعال‌سازی خودکار RDP (رجیستری + فایروال 3389 + سرویس).
• رفع کندی صفحه جزئیات/شارژ مشتری (رهرو غیرمسدودکننده).

ساختار
------
client/       GameNet-0.2.5-win7-ia32.exe (نصب کامل)
              GameNet-Client-Update-0.2.5.exe (آپدیتر app.asar)
              app.asar + latest.json
server-hub/   GameNet-Server-0.2.5-Setup.exe (نصب کامل)
              GameNet-Server-Update-0.2.5.exe (آپدیت درجا)
              GameNet-Server-Update-0.2.5.zip (آپدیت از راه دور)
              latest.json
cloud/        gamenet-cloud-0.2.5.tar.gz + deploy_cloud_update.sh

ترتیب پیشنهادی
---------------
۱) ابر (در صورت نیاز):
   bash deploy_cloud_update.sh gamenet-cloud-0.2.5.tar.gz

۲) سرور هاب:
   - نصب تازه: GameNet-Server-0.2.5-Setup.exe (Run as administrator)
   - آپدیت:    GameNet-Server-Update-0.2.5.exe (Run as administrator)
     (پوشه backend\data و .env حفظ می‌شوند)
   - از راه دور: بسته zip از پنل ابر برای هاب ارسال شود.

۳) کلاینت‌ها:
   - خودکار از هاب (نسخه 0.2.5 در heartbeat اعلام می‌شود)
   - یا دستی: GameNet-Client-Update-0.2.5.exe (Run as administrator)
   - یا نصب کامل: GameNet-0.2.5-win7-ia32.exe

بررسی سلامت
------------
- هاب: فوتر پنل باید GameNet v0.2.5 باشد؛ تغییر رمز بدون خطا انجام شود.
- کلاینت: در صفحه قفل v0.2.5 دیده شود.
- ابر: /healthz = 200 و صفحه devices/ شامل «نمای جدولی».
